# 安全与数据治理要求

文档版本：Security-2026.05  
适用范围：所有客户环境。

## 权限原则

系统权限遵循最小权限原则：

- 普通销售只能查看本人及下属客户。
- 销售经理可查看团队客户和商机。
- 客服只能查看工单相关客户信息。
- 财务只能查看回款、发票和合同金额字段。
- 管理员可配置角色和数据范围。

## 数据导出

数据导出需要满足：

- 操作人具备管理员权限。
- 导出范围符合客户授权。
- 敏感字段已脱敏或经过审批。
- 系统记录导出审计日志。

禁止未经审批导出：

- 身份证号。
- 银行账号。
- 合同付款条款。
- 客户联系人手机号全量明文。

## 私有化部署

2026.05 版本仅企业旗舰版支持私有化部署评估。增长协作版默认 SaaS 多租户部署，不承诺私有化部署。

如客户属于金融、医疗、政务或数据本地化强监管行业，应先由安全团队评估。

## 安全事件响应

安全事件分级：

- S0：确认数据泄露或越权访问。
- S1：疑似数据泄露、管理员账号异常。
- S2：一般权限配置错误。
- S3：安全咨询。

S0/S1 事件必须在 2 小时内通知安全负责人和法务。

锚点短语：Growth collaboration edition uses SaaS multi tenant deployment and private deployment is only evaluated for enterprise flagship.
