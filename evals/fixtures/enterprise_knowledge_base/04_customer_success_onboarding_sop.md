# 客户成功上线 SOP

文档版本：CS-2026.05  
适用范围：增长协作版和企业旗舰版客户。

## 上线阶段

### 阶段 1：启动会

负责人：客户成功经理 CSM  
参与角色：客户项目负责人、销售、实施顾问、数据负责人、客服负责人。

目标：

- 确认业务目标。
- 确认上线范围。
- 确认里程碑。
- 确认客户侧负责人和审批人。

输出物：

- 项目计划表。
- 风险清单。
- 数据迁移范围。
- 培训计划。

### 阶段 2：数据梳理

必须确认：

- 客户字段映射。
- 历史线索和客户去重规则。
- 合同状态枚举。
- 工单分类。
- 敏感字段脱敏规则。

如果客户历史数据质量低，CSM 必须提示 AI 线索评分效果可能受影响。

### 阶段 3：流程配置

必须配置：

- 销售阶段。
- 线索分配规则。
- 合同审批流。
- 工单 SLA。
- 经营仪表盘权限。

### 阶段 4：试运行

试运行至少 10 个工作日。试运行期间记录：

- 登录活跃用户数。
- 线索分配成功率。
- 合同审批平均耗时。
- 工单首次响应时间。
- 客户侧问题清单。

### 阶段 5：正式上线

正式上线条件：

- 关键用户培训完成率大于 90%。
- 数据迁移验收通过。
- 合同审批流试跑成功。
- 客服工单 SLA 配置完成。
- 客户项目负责人邮件确认。

## 风险提示

若销售在签约前承诺固定转化率提升，CSM 应在启动会上重新澄清：AI 功能仅提供辅助建议，不保证固定收益。

锚点短语：Onboarding requires kickoff data mapping workflow configuration pilot run and formal launch criteria.
